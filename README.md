# Devscope
DevScope is a web application designed to help users explore GitHub developers and manage a shortlist of interesting profiles.

Its main functionality includes:
- GitHub API integration: Retrieve developer profiles and repository information dynamically.
- Profile exploration: Display GitHub user information and repositories.
- Candidate management: Shortlist developers and organize profiles.
- Evaluation system: Track candidate status and ratings.
- Data optimization: Cache retrieved data locally to reduce unnecessary API requests.
- User interface: Interactive interface built with JavaScript and Tailwind CSS.
The project demonstrates practical skills in consuming external APIs, asynchronous JavaScript, DOM manipulation, data management and building interactive web interfaces.
